# Мир аналитика данных — сайт-блог

Сайт, на который автоматически копируются посты из Telegram-канала
[@analysts_world](https://t.me/analysts_world). Работает на GitHub Pages, бесплатно.

## Как это работает

1. Раз в час GitHub Actions запускает `scripts/fetch-telegram.mjs`.
   Скрипт читает веб-версию канала `t.me/s/analysts_world` и сохраняет новые посты
   в `content/posts/<номер>.json`, а картинки — в `public/media/`.
2. Новые посты коммитятся в репозиторий.
3. Сайт собирается генератором [Astro](https://astro.build) и публикуется на GitHub Pages.

Посты появляются на сайте с задержкой до часа. Запустить синхронизацию вручную:
вкладка **Actions** → «Синхронизация с Telegram и публикация» → **Run workflow**.

## Что где менять

| Что | Где |
|---|---|
| Тексты, цифры на главной, ссылки, фото | `site.config.mjs` |
| Рубрики и ключевые слова для них | `site.config.mjs` → `rubrics` |
| Счётчики Яндекс Метрики / PostHog | `site.config.mjs` → `analytics` |
| Цвета и шрифты | `src/styles/global.css` (переменные в начале файла) |
| Главная страница | `src/pages/index.astro` |
| Страница поста | `src/pages/posts/[id].astro` |

## Аналитика и события

Впишите номер счётчика Яндекс Метрики и/или ключ PostHog в `site.config.mjs` —
счётчик подключится на всех страницах.

Свои события:
- в разметке: атрибут `data-track="имя_события"` на ссылке или кнопке — клик отправится сам
  (уже стоит на кнопках Telegram, LinkedIn, «Открыть в Telegram»);
- в коде: `window.track('имя_события', { параметр: 'значение' })`.

В Метрике события приходят как цели (`reachGoal`), в PostHog — как `capture`.

## Запуск на своём компьютере

```bash
npm install
npm run fetch   # докачать посты
npm run dev     # сайт на http://localhost:4321
```

## Первая публикация

1. Создайте на GitHub публичный репозиторий **vshuvaeva.github.io**.
2. Загрузите в него этот проект (ветка `main`).
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Через пару минут сайт откроется по адресу https://vshuvaeva.github.io.

> Если у репозитория другое имя (например, `blog`), сайт будет по адресу
> `https://vshuvaeva.github.io/blog/` — тогда в `astro.config.mjs` впишите `base: '/blog'`.

GitHub отключает расписание в репозиториях без активности 60 дней. Пока в канал
выходят посты, робот сам делает коммиты и расписание не отключается.
